Privacy Policy

Last updated: 2026-09-29

Who uses this app

gws-personal is used only by its developer to access the developer's own Google accounts. It is not offered to the public.

Data accessed

With the developer's consent, the app accesses Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets, Google Slides, Google Tasks and Google Contacts data of the developer's own accounts.

How data is used

Data is processed only on the developer's own computer to organize the developer's accounts (for example, migrating calendar events and reviewing email senders). Data is not sold, not shared with third parties, and not used for advertising.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

OAuth tokens are stored encrypted on the developer's computer. Access can be revoked at any time from Google Account > Third-party connections.

プライバシーポリシー（日本語）

本アプリは開発者本人が自分の Google アカウントを管理するためだけに使用します。取得したデータは開発者のPC上でのみ処理し、第三者への提供・販売・広告利用は行いません。Google API から取得した情報の利用は Google API Services User Data Policy（Limited Use 要件を含む）に従います。認証情報はPC上に暗号化して保存し、Google アカウントの「サードパーティとの接続」からいつでも取り消せます。
